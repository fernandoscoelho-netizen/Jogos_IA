Como são escolhidos os desafios

Cada missão tem três grupos. O jogo sorteia uma variante de cada um dos dois primeiros grupos para o 5.º/6.º ano; para o 7.º/8.º/9.º ano, sorteia também uma do terceiro. Mantêm-se 12 ou 18 desafios por sessão e 600 pontos no total. Há variantes em todos os grupos: bandeiras, pertença à UE, símbolos, funções institucionais, cronologia, direitos, orçamentos, cooperação e análise de afirmações.

A seleção é feita ao começar e não muda ao voltar a uma missão. As opções e as linhas são baralhadas com remapeamento da resposta correta. A ordenação nunca começa já resolvida. A variante imediatamente anterior de cada grupo é excluída no próximo sorteio. Isto não impede que uma variante volte a aparecer noutras sessões. O navegador guarda apenas esses identificadores, sem dados pessoais ou respostas; se não permitir armazenamento local, essa memória dura enquanto a página estiver aberta.

Acrescentar uma variante sem instalar ferramentas

  1. Antes de começar, abre «Base de desafios» e descarrega a base atual. Também encontras o ficheiro em content/banco-desafios.json.
  2. Abre uma cópia num editor de texto. Em missions, escolhe a missão, o grupo em slots e a lista variants. Duplica uma variante do mesmo tipo.
  3. Atribui um id único, com letras minúsculas, números e hífen. Altera o enunciado, opções, solução, pista e explicação. Usa apenas texto simples, sem HTML. Mantém a relação com a aprendizagem e revê o rigor.
  4. Guarda o JSON em UTF-8. No jogo, usa «Base de desafios» e escolhe o ficheiro. Uma mensagem confirma o carregamento ou explica o erro. Uma base inválida não substitui a anterior.
  5. Começa uma nova aventura. O carregamento vale apenas para essa página aberta; atualizar volta a carregar a base incluída no jogo.

A validação verifica a estrutura, identificadores, opções, referências e coerência dos custos. Não verifica automaticamente a verdade histórica ou científica dos textos. Mantém as seis missões e os três grupos; só o terceiro tem advanced: true. Mantém as primeiras 14 fontes na mesma ordem e acrescenta novas fontes no fim. Os índices das fontes começam em zero. As bandeiras disponíveis são as 27 incluídas.

Campos dos desafios

Todos têm id, type, title, intro, clue, explain, refs. A pista tem de permitir resolver a variante escolhida e a explicação deve justificar a solução.

  • choice: options é a lista de opções; answer é o índice correto, começando em 0.
  • match: rows contém pares [enunciado, resposta]; cada resposta tem de constar em options. Se houver flags, é uma lista dos códigos das imagens correspondente à ordem das linhas.
  • order: items contém os acontecimentos; answer contém os mesmos acontecimentos na ordem correta.
  • budget: options e costs têm a mesma ordem; answer é a lista dos índices das ações certas; limit é o orçamento. Explicita os objetivos e os custos na pista. Os cenários e valores são fictícios.

Exemplo de escolha

{
  "id": "simbolos-nova-variante",
  "type": "choice",
  "title": "Revê a legenda.",
  "intro": "As estrelas da bandeira contam os países da UE?",
  "clue": "A bandeira tem 12 estrelas. O número não depende dos Estados-Membros.",
  "options": ["Sim", "Não"],
  "answer": 1,
  "explain": "As 12 estrelas simbolizam unidade, solidariedade e harmonia.",
  "refs": [9]
}

Para manter uma base editada na distribuição

O jogo usa uma cópia JavaScript do JSON para poder abrir como ficheiro local, sem fetch ou servidor obrigatório. Alterar só o JSON da pasta não altera automaticamente essa cópia. Para uso imediato, carrega o JSON pela interface. Para uma distribuição permanente, pede a sincronização de banco-desafios.js com o JSON. Foi incluído tools/sincronizar-base.cjs para quem já tenha Node.js: executa node tools/sincronizar-base.cjs a partir da pasta do jogo. Node.js não é necessário para jogar nem para carregar um JSON na interface.

Referências da sessão e manual do professor

Durante uma sessão, a mesma janela permite descarregar os identificadores dos desafios sorteados em JSON. Os identificadores permitem localizar as variantes na base; não permitem reabrir automaticamente uma sessão. O caderno apresenta as pistas e explicações da seleção efetivamente jogada.

O manual PDF anterior mantém as propostas de aula e avaliação. Os guiões de soluções das páginas 4 a 9 devem ser lidos como exemplos. Num orçamento novo, confirma o limite e os objetivos na pista: não assumas que o valor é sempre 6 créditos. Os limites dos testes continuam descritos em VERIFICACAO.md.
